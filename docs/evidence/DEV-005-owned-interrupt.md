# DEV-005 中断请求归属派发

日期：2026-10-25。需求关联：FR-05、FR-09；路线图：M0 上游中断映射与 M1 Host 操作状态机。项目仍处 M0。

## 行为

- 有界内存队列只传已持久中断操作的操作者与请求号。当前连接所有者从操作读取 run，并在当前 epoch 核对活动槽、session/thread 绑定和上游 turn；一次领取派发权后发送 `turn/interrupt`。
- 正常 RPC 响应只保留 `dispatching`，由独立 `turn/completed` 终态确认最终状态。匹配的 RPC 错误记为未知并继续读取同一连接，避免丢弃可能已缓冲的完成事件；传输失效关闭连接、保留未知并执行 `upstream_exit` 恢复。
- 重复队列项、已终态操作和绑定不符的请求不再发送；发送故障不自动重试。
