# DEV-005 归属连接单步事件泵

日期：2026-10-25。需求关联：FR-02、FR-04、FR-09；路线图：M0 上游映射与 M1 Host 生命周期。项目仍处 M0。

## 行为

- 只在持锁 Host 的当前 epoch 且连接归属匹配时读取一条上游消息。已识别的审批请求、请求结束和回合终态交给现有单事务适配器；空等待不改变状态。
- 读取、消息验证或持久化失败时，关闭归属 stdio 连接与 Windows Job，核对受管进程退出，再按活动回合执行 `upstream_exit` 恢复。返回有限的故障类别，不返回原始消息或数据库内容。
- 若恢复事务也失败，保持原 epoch 与关闭的写门控；不继续消费该连接，也不重发可能已生效的请求。

## 验证与限制

`python scripts/check.py`：16 份契约通过；206 项测试运行，201 通过、5 项因本环境链接创建或回环连接限制跳过。Windows 合成 peer 测试覆盖三类消息顺序、空等待、上游退出、审批事件写入故障、恢复事务写入故障、伪造归属与无效超时。

`scripts/smoke_package.ps1`：离线 wheel 构建、隔离安装、已安装 CLI 的 16 份契约核对及新增模块导入通过。

这是有界单步入口，不是产品长期事件循环。审批答复调度、真实 Codex 并发时序、Host 崩溃后的旧进程隔离证明和产品 API 仍未完成。
