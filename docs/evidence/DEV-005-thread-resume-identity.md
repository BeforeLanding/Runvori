# DEV-005 历史 thread 恢复身份核对切片

日期：2026-10-25。需求关联：FR-02、FR-08、FR-09；路线图：M0 兼容映射与 M1 Host 生命周期。项目仍处 M0。

## 行为

- 共享 Host 只有在持锁统一恢复成功且调用方提供当前 epoch 后，才读出 session/thread 持久绑定。适配器调用 `thread/resume`，要求响应中的 `thread.id` 与绑定完全一致；错误身份、上游拒绝或无响应时关闭该连接，绑定保持不变，不自动创建替代 thread。
- 新回合一次派发在当前上游连接先完成上述身份核对，再领取 `turn/start` 发送权。核对失败时已受理操作仍为 `accepted`，活动回合仍为 `starting`，没有发送 `turn/start`。
- 成功核对只表示当前连接识别该 thread，不表示旧回合可无损续跑；旧活动回合仍须按进程隔离和统一恢复处理。
