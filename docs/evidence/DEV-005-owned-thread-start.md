# DEV-005 本地 thread 创建归属调度

日期：2026-10-25。需求关联：FR-02、FR-08、FR-09；路线图：M0 上游映射与 M1 Host 生命周期。项目仍处 M0。

## 行为

- 有界队列只接受 `local` 操作者以及会话/请求标识，不承载 cwd、策略或任意上游参数。入队只是内存信号，不是持久受理。
- 当前连接所有者在 SQLite 所在线程消费信号，调用既有一次创建适配器，从已登记工作区读取路径和策略、记录意图、领取发送权、核对返回的 thread ID 并绑定会话。
- 重复已确认信号返回原绑定，不再次发送；响应丢失时记录未知，隔离连接并完成 `upstream_exit` 恢复，旧循环不消费剩余信号。

## 验证与限制

`python scripts/check.py`：16 份契约通过；219 项测试运行，214 通过、5 项因本环境链接创建或回环连接限制跳过。定向测试覆盖队列容量与本地标识限制、重复信号、响应丢失及缺失会话拒绝。

`.\scripts\smoke_package.ps1`：离线 wheel 构建、隔离安装、已安装 CLI 的 16 份契约核对及新增模块导入通过。本轮未发现需新增至错误记录的故障。

队列满或 Host 在消费前退出时，没有持久创建意图；调用方不得把入队当作已受理。产品本地入口、`thread/resume` 与 `turn/start` 的同所有者调度、真实 CLI 并发时序以及 Host 崩溃后的旧进程隔离证明仍未完成。
