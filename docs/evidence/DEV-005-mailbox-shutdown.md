# DEV-005 Host 邮箱停机边界

日期：2026-10-26。需求关联：FR-03、FR-06、FR-09；路线图：M1 Host 生命周期。项目仍处 M0。

## 行为

- 归属事件循环停止、上游恢复或异常退出时关闭所使用的命令邮箱；测试用 `handoff_limit` 返回不关闭，仍可继续消费。关闭可重复调用，唤醒增量事件等待并拒绝后续入队。
- 已排队或正在等待结果的读取返回 `host_stopped`；已提交情况可能不明的回合启动与中断返回 `command_result_unknown`，调用方须保留原请求号，在可用的新 Host 上查询，不据此重发。
- 关闭不写 SQLite，不把空事件页或超时冒充正常停机结果。该生命周期属于当前进程内的邮箱实例，尚未等同于产品 Host 停机、配对撤销或 HTTP 请求取消。
