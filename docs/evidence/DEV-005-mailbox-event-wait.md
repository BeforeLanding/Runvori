# DEV-005 命令邮箱增量事件等待

日期：2026-10-26。需求关联：FR-03、FR-06；路线图：M1 Host 最小协议的事件同步前提。项目仍处 M0。

## 行为

- 内部邮箱的 `wait_session_events` 仅接受 `wait_ms` 0–25000 和增量游标。0 立即读取；正值在请求线程等待，以最多 250 毫秒间隔重新提交只读分页命令。SQLite 所有者不会因等待而阻塞上游事件或其他命令。
- 新事件到达后返回已提交事件及其连续序号；空超时返回空 `events` 和原 `next_after_seq`，不写心跳事件、不推进游标。游标错误或所有者处理超时保持错误，不伪装成空页。
- 等待只依赖已有事件库读事务与分页字节上限，没有新的数据库状态或上游 RPC。
