# DEV-005 已受理回合归属调度

日期：2026-10-25。需求关联：FR-02、FR-08、FR-09；路线图：M0 上游映射与 M1 Host 生命周期。项目仍处 M0。

## 行为

- 有界内存队列携带原 session、run、操作者、请求号、预期版本及不超过 16 KiB 的输入；不接受调用方指定上游 thread ID。队列不替代已持久受理的操作，不记录输入到诊断。
- 当前连接所有者核对操作与输入摘要，读取不可改写的 thread 绑定，先 `thread/resume` 核对身份，再领取一次 `turn/start` 发送权。响应绑定后才从同一连接消费并持久化此前缓冲的审批请求。
- 输入冲突或重复信号不再发送。恢复身份失败、领取事务故障或回合响应未知时隔离连接、恢复 epoch，旧循环不消费剩余队列项。
