# DEV-005 已提交事件的等待通知

日期：2026-10-26。需求关联：FR-03、FR-06；路线图：M1 Host 事件同步前提。项目仍处 M0。

## 行为

- 内部命令邮箱维护线程安全的变更代次。请求线程先读取持久事件页；若为空，则在条件变量上等待。通知发生在查询与开始等待之间时，代次变化使它立即重查，不丢唤醒。
- 邮箱受理的持久回合/中断操作以及归属连接的事件交接完成后发出提示。提示可能没有对应的新事件，等待线程必须重新查询 SQLite，不把提示当作事件或推进游标。
- 最多 250 毫秒的定时复查仍覆盖未接入通知的本地写路径；超时空页和游标语义保持不变。
