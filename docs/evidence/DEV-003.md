# DEV-003：审批传输准备记录

日期：2026-10-23，Asia/Shanghai。状态：真实命令审批拒绝与单次允许路径已观察；文件审批、中断与 M0 退出条件未完成。对应 FR-04、FR-05、FR-08、FR-09 的上游技术前提，尚不构成 AT-04～AT-07、AT-15、AT-16 的产品验收。

## 本轮行为

- 已知的 `item/commandExecution/requestApproval` 和 `item/fileChange/requestApproval` 可作为事件读出；即使请求先于 `turn/start` RPC 响应到达，也不会遗失。
- 调用方必须显式选择 `accept` 或 `decline`。同一请求 ID 只发送一次；不接受 `acceptForSession`、策略扩权和未知控制请求。写入超时后结果不确定，连接失效且不自动重发。
- 这只是顺序探针传输。已处理收到的上游请求结束通知；尚未持久化审批或实现生产级并发调度。
- 新增显式启用的执行探针：只能使用仓库 `.dev` 内带标记的空 Git 测试仓库；账号目录与审批决定是必填参数。固定受限工作区及逐次审批，按 `thread/start → turn/start → turn/completed → thread/resume` 采集事件形状和实际文件核对，报告不写上游字符串值。
- 真实拒绝审批路径观察到 `item/commandExecution/requestApproval`，传输层发送一次 `decline` 后收到 `serverRequest/resolved`，回合最终 `completed`，`thread/resume` 可识别原 thread；目标文件不存在、命令项退出码为 null。请求结束通知不证明批准生效或命令成功。脱敏形状夹具见 [JSON](DEV-003-command-declined.json)。
- 传输层在收到 `serverRequest/resolved` 后撤销尚未回复的审批，迟到的允许/拒绝均被拒绝；真实通知中的 `requestId` 为整数，合成回归覆盖该类型。
- 允许探针只对测试仓库内已审查的只读 `python --version`（或本机固定 Codex PowerShell 包装形式）回复单次 `accept`；校验回合、命令、cwd 和权限字段。其他请求仍回复 `decline`，报告逐项记录实际决定，避免把 `--approval accept` 模式误读为所有请求均已允许。

## 真实受限执行观察

使用已登录的独立 `.dev/codex-home` 与 `.dev/execution-fixture`，固定 `workspace-write`、`on-request`、`approvalsReviewer=user`，自动拒绝所有已识别审批。

首次运行在普通沙箱中得到 `turn_status=failed`、0 次审批、无目标文件；同环境 `Test-NetConnection api.openai.com -Port 443` 无法解析域名。该网络限制是失败的强相关证据，未从上游原始错误码确认单一根因。失败报告保留在被忽略的 `.dev/execution-probe-sandbox-failed.json`。

在允许外网访问的本机执行环境中重跑同一空测试仓库：`turn_status=completed`、1 次命令审批、决定 `decline`、`resume=recognized`、`file_match=false`。共有 91 个事件；第 35 个为命令审批请求，第 36 个为请求结束通知，第 90 个为回合终态。上游正文、命令及个人路径均未进入已提交的脱敏夹具。两次运行均未观察文件修改审批；真实中断未运行。

## 真实单次允许观察

首次尝试写文件命令时，审批参数出现导出 schema 未列出的 `availableDecisions`，且命令正文不在白名单，探针安全拒绝。改用只读命令后，通过本地临时审查确认真实命令由 Codex 随附 PowerShell 包装；审查文件随即删除，未提交命令或个人路径。后续请求还携带 `environmentId` 和 `proposedExecpolicyAmendment`；裸 `accept` 与 `acceptWithExecpolicyAmendment` 在协议中是不同决定，因此探针只发送本次允许，不应用建议的策略修订。网络权限请求仍禁止放行。

最终重跑观察到 1 次命令审批，白名单核对通过并发送一次 `accept`；对应命令项返回退出码 0，随后回合 `completed`，原 thread 可恢复。只读场景不创建目标文件，`file_match=false` 是预期结果。脱敏形状夹具见 [JSON](DEV-003-command-accepted.json)。`serverRequest/resolved` 仅表示请求结束；命令成功依据对应 item 的真实退出码，不由通知或回合终态推断。

`availableDecisions` 在真实消息中出现，但当前导出的对应 schema 未声明它；本版本映射需保留这条差异并在升级时复核。尚未验证允许写文件后的差异、文件修改审批、主动中断、请求清理与中断竞争、Host 重启。下一步以同样的具体操作审查方式采集文件与中断证据，不把只读命令结果外推到这些路径。
