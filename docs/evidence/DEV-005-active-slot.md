# DEV-005 全局活动槽事务切片

日期：2026-10-25。需求关联：FR-02、FR-08、FR-09；路线图：M1 Host 持久化与最小协议。本仓库仍处 M0；此项是 M1 的独立数据库前提，未接入产品 Host。

## 实现与失败边界

- 在事件库中加入 `runs`、固定一行的 `active_slot` 和 `session_version`。本阶段从前一事件库 schema v1 升级到 v2，保留原会话、事件和快照；后续请求幂等切片升级为 v3，见 [记录](DEV-005-run-idempotency.md)。未知版本拒绝打开。此处没有生产部署数据迁移承诺。
- `reserve_run` 在 `BEGIN IMMEDIATE` 事务内核对会话版本和全局槽，登记 `starting` 回合、占槽、追加 `run.created` 并更新快照和版本。两个会话并发创建只能有一个成功。RPC 尚未发送，故此事件只表示本地已持久预留。
- `finish_run` 在同一事务内写终态事件与快照、更新回合版本、按 `run_id` 释放槽；同一终态重复到达不增加事件，相反终态拒绝。旧回合的重复终态不能释放后续回合的槽。
- 插入事件失败或快照更新失败会回滚整次状态变化。普通事件追加入口拒绝直接伪造 `run.created` 和终态事件。
