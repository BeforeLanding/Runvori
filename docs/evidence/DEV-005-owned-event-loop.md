# DEV-005 归属连接持续事件循环

日期：2026-10-25。需求关联：FR-02、FR-04、FR-09；路线图：M0 上游映射与 M1 Host 生命周期。项目仍处 M0。

## 行为

- `run_owned_event_loop` 在持锁且归属匹配的 Host 线程中重复调用已有单步交接，使用有界轮询超时，空等待不改变状态。
- 外部停止信号在消息间生效；可选交接数上限用于有界运行。上游故障恢复后立即退出旧连接循环，不对新 epoch 自动重启。
- 返回只包含消息种类计数、退出原因及有限的恢复类别，不记录消息正文。
