# DEV-005 会话与上游 thread 持久归属切片

日期：2026-10-25。需求关联：FR-02、FR-08、FR-09；路线图：M0 兼容映射与 M1 Host 状态。项目仍处 M0。

## 行为与迁移

- 事件库 schema 升至 v7，新增 `session_threads`：每个 session 最多绑定一个不可改写的上游 thread，同一 thread 只能属于一个 session。绑定受共享库恢复前写门控约束；读取跨重开保持一致。`confirm_run_started` 对已绑定会话拒绝其他 thread。
- 新回合派发只从数据库读取 thread ID，不再接受调用方临时指定。未绑定会话不能领取或发送 `turn/start`。
- v6 库升级时保留会话、回合和已记录上游 turn；不根据历史数据自动猜测缺失的会话归属。受信任本地流程补记绑定时，若已有 turn 记录指向其他 thread 则拒绝。
