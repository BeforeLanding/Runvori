# DEV-005 上游连接唯一归属切片

日期：2026-10-25。需求关联：FR-02、FR-09；路线图：M0 进程边界与 M1 Host 生命周期。项目仍处 M0。

## 行为

- 持锁 Host 完成统一恢复后，按当前 epoch 预留唯一上游连接位，再启动并初始化 Windows `StdioClient`。同一实例重复启动和旧 epoch 启动拒绝；初始化失败须先关闭受管进程与 Job，确认隔离后才能释放连接位。
- 退出恢复只接受该 Host 记录的归属对象。伪造对象不能关闭真实连接或推进 epoch；仍有活连接时，直接调用恢复事务也会拒绝并关闭写门控。恢复成功后释放连接位，新 epoch 可启动新连接。
- Host 关闭时先关闭仍归属的连接并核对父进程及 Job 句柄，再释放数据库与实例锁。隔离不确定时保留锁和关闭的写门控。

## 验证与限制

`python scripts/check.py`：16 份契约通过；201 项测试运行，196 通过、5 项因本环境链接创建或回环连接限制跳过。Windows 合成 peer 测试覆盖活动回合恢复、关闭失败写门控、旧 epoch 拒绝、重复启动、伪造归属、活连接直接恢复拒绝、初始化失败清理及 Host 关闭顺序。

`scripts/smoke_package.ps1`：离线 wheel 构建、隔离安装、已安装 CLI 的 16 份契约核对及模块导入通过。

归属约束仅在当前 Host 进程内成立。Host 崩溃后旧进程隔离、产品事件循环与当前锁定 CLI 的真实联调尚未完成；Job 管理不替代执行权限沙箱。
