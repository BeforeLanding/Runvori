# DEV-005 本地撤销与在途读取取消

日期：2026-10-26。需求关联：FR-01、FR-03、FR-06；路线图：M1 Host 最小协议。项目仍处 M0。

## 行为

- `DeviceReadGateway.revoke_local_device()` 仅供可信 Host 本地入口调用。它先在配对库提交唯一设备撤销，再向该网关实例登记中的读取发取消信号，并唤醒邮箱等待。
- 网关为每次读取登记取消信号；快照尾页也可传入取消信号。排队读取和长轮询在撤销后及时退出，不返回已读取数据。共享同一取消信号的并发读取采用引用计数，结束后移除登记。
- 即使直接通过配对库撤销而绕过此网关，上一轮的读取前后鉴权与最长 250 毫秒分段复核仍生效。直接撤销不具备主动唤醒保证。

## 验证与限制

`python scripts/check.py`：16 份契约通过；266 项测试运行，261 通过、5 项因本环境链接创建或回环连接限制跳过。新增行为测试覆盖本地撤销主动唤醒长轮询、取消排队中的快照读取、撤销后的新读取拒绝，以及在途登记清理。`.\scripts\smoke_package.ps1`：离线 wheel 构建、隔离安装、已安装 CLI 契约校验和模块导入通过。

本地管理入口尚未接入该方法；产品 HTTP/TLS 和 Android 请求仍未实现。该取消仅覆盖当前网关实例；若其他进程或代码直接修改配对库，只能靠定时复核。一次读取完成后与未来 HTTP 响应发送之间仍有竞态，正式发送前必须再次校验设备身份。
