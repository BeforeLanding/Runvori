# DEV-005 本地工作区登记与创建归属切片

日期：2026-10-25。需求关联：FR-02、FR-08、FR-09；路线图：M0 兼容映射与 M1 Host 生命周期。项目仍处 M0。

## 行为

- 共享 Host 在持锁统一恢复后登记本地工作区 ID、绝对根目录和 `read-only|workspace-write` 沙箱策略；相同登记幂等，路径或策略冲突拒绝，符号链接与 junction 路径拒绝。
- 事件库 schema v9 增加 `workspaces` 与 `session_workspaces`。新会话和工作区归属在同一事务中提交；关联失败时会话也回滚。旧库升级保留已有会话但不猜测其工作区归属。
- `thread/start` 不再接收调用方路径和沙箱参数。适配器从会话登记读取两者，发送前复查目录；未登记或目录已消失时不记录创建意图、不调用上游。

## 验证与限制

`python scripts/check.py`：16 份契约通过；195 项测试运行，190 通过、5 项因本环境链接创建或回环连接限制跳过。SQLite 与合成 stdio 测试覆盖旧库升级、登记重放与冲突、未登记旧会话拒绝、会话关联故障回滚、从登记策略生成创建参数及目录消失后的发送拒绝。

`scripts/smoke_package.ps1`：离线 wheel 构建、隔离安装、已安装 CLI 的 16 份契约核对及模块导入通过。

尚无可供用户使用的本地管理入口、真实 Codex 联调或生产级路径竞态防护。路径检查与上游实际打开目录之间仍可能发生替换，需在产品进程与工作区所有权编排中继续收紧。
