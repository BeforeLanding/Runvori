# DEV-005 未派发回合取消

日期：2026-10-26。需求关联：FR-05、FR-09；路线图：M0 中断映射与 M1 Host 操作状态机。项目仍处 M0。

## 行为

- `starting` 回合的启动操作仍为 `accepted`、尚无派发 epoch 且无上游 turn 绑定时，中断请求和终态在同一个 SQLite 事务中写入。启动操作为 `failed/cancelled_before_dispatch`，中断操作为 `confirmed/run_interrupted`，活动槽释放。相同请求重放返回原操作；后续启动队列信号不能领取发送权。
- `turn/start` 发送权已领取但 turn 尚未绑定时返回 `turn_not_bound`，不释放活动槽、不推断上游未执行。该路径仍需绑定后的中断或进程隔离恢复。
- 任一事件写入失败时，启动操作、回合、活动槽和中断操作全部回滚。
