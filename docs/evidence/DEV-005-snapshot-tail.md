# DEV-005 快照与最近事件同事务读取

日期：2026-10-26。需求关联：FR-03、FR-06；路线图：M1 Host 持久化与最小协议的快照读取前提。项目仍处 M0。

## 行为

- 事件库在一个 SQLite 读事务中读取会话快照、`snapshot_seq` 和不晚于该序号的最近事件。尾页按 seq 升序返回，`history_before_seq` 指向已选最早事件；空尾页使用 `snapshot_seq + 1`，可直接作为历史页的排他游标。
- 从最新事件向前选取，最多 100 条，并根据存储的事件字节数和完整响应大小裁剪，确保快照与尾页合计不超过 256 KiB。`snapshot()` 原有原始读取行为保持不变。
- 内部命令邮箱可请求该读取模型；Host 身份、服务时间、设备鉴权和 HTTP 响应映射仍未接入。
