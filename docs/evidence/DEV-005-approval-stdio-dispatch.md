# DEV-005 审批一次派发与 stdio 答复切片

日期：2026-10-25。需求关联：FR-02、FR-04、FR-09；路线图：M0 兼容映射与 M1 审批派发。项目仍处 M0。

## 行为

- 派发适配器只从已持久化的审批操作读取决定、类型化上游 JSON-RPC 请求号和请求摘要。旧探针或非规范请求号不能进入发送路径；调用方不能另传决定或上游请求号。
- 先在单库领取一次派发机会并提交，再调用 `StdioClient.respond_approval`。写入返回后仍保持 `dispatching`；只有独立请求结束通知才能确认请求已结束。发送异常时关闭上游客户端，并将已领取的审批和操作持久记为 `unknown/dispatch_unconfirmed`，不重发。
- 上游请求号 `int:23` 和 `str:23` 保持类型区别；非规范整数、空标识、超限和非法 Unicode 标识拒绝。
