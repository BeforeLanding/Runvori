# DEV-005 上游单消息持久交接切片

日期：2026-10-25。需求关联：FR-02、FR-04、FR-09；路线图：M0 兼容映射与 M1 Host 事件路径。项目仍处 M0。

## 行为

- `process_next_event` 从现有 `StdioClient` 读取至多一条消息，将命令/文件审批请求、`serverRequest/resolved` 和 `turn/completed` 交给对应的单库适配器。超时返回空；未知可选通知只返回不含原始内容的诊断标记；未知控制请求拒绝。
- 已识别消息持久化失败或读取失败时关闭上游客户端，不继续消费或答复审批。该入口不自动答复审批，也不承担进程启动、turn 绑定、重连、长期队列或产品服务循环。
- 审批请求落库时，只有 SQLite 唯一键/主键冲突归类为重复请求；其他完整性错误原样传播，供连接停止及恢复处理。

## 验证与限制

`python scripts/check.py`：16 份契约通过；165 项测试运行，160 通过、5 项因本环境链接创建或回环连接限制跳过。合成 JSONL peer 验证请求 → 回合终态 → 晚到请求结束的顺序交接；事件写入故障使审批事务回滚并关闭客户端。另测超时、未知通知、未知控制请求和读取失败。

`scripts/smoke_package.ps1`：离线 wheel 构建、隔离安装、已安装 CLI 的 16 份契约核对及新模块导入通过。

尚未接入当前锁定 CLI 的真实审批/终态竞态或产品 Host 生命周期；合成 peer 不证明真实消息时序，也不证明进程隔离与恢复条件成立。
