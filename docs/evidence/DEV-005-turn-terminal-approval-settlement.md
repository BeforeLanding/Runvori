# DEV-005 回合终态审批收尾切片

日期：2026-10-25。需求关联：FR-02、FR-04、FR-09；路线图：M0 兼容映射与 M1 审批状态。项目仍处 M0。

## 行为

- 已绑定的 `turn/completed` 进入单库事务后，按同一 run 和 epoch 处理未结束审批，再写回合终态、快照并释放活动槽。待决定审批失效；已记录但未领取的决定失效，操作记 `failed/turn_terminal_before_dispatch`；已领取未确认的审批与操作记 `unknown/turn_terminal_dispatch_unconfirmed`；原本未知的保持未知。终态通知不能证明批准生效、工具副作用或请求已经清理。
- 对多个审批逐项写 `approval.updated` 和必要的 `operation.updated`。任何事件写入失败均回滚整个收尾、终态和活动槽释放。重复相同终态不再次收尾。
- 若已失效审批随后收到匹配的请求结束通知，只补记 `request_closed` 证据；审批保持失效，未派发操作保持失败。已领取后转未知的审批仍可由结束通知按原规则转为 `resolved`，但不推断工具成功。
