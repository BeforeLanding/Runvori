# DEV-005 Host 身份持久化

日期：2026-10-26。需求关联：FR-01、FR-06；路线图：M1 Host 最小协议。项目仍处 M0。

## 行为

- 事件库 schema v11 在权威 Host 数据库中保存一个随机、不由路径或时间推导的 `host_id`。新库只生成一次，重开保持不变；另建数据库得到新身份。
- v0～v10 库升级时，身份写入与 `user_version=11` 在同一事务内提交，不改已有会话和事件。已标记 v11 却缺失或损坏身份的库拒绝打开，不暗中补造身份。
- SQLite 所有者可经内部命令邮箱读取该身份，其他线程不直接触碰数据库连接。身份不包含设备令牌、模型凭据或本机路径。

## 验证与限制

`python scripts/check.py`：16 份契约通过；272 项测试运行，267 通过、5 项因本环境链接创建或回环连接限制跳过。新增 3 项事件库行为测试覆盖重开/新库、v10 升级保留会话与损坏拒绝、升级写入失败回滚；已有跨线程邮箱测试补充身份读取。`.\scripts\smoke_package.ps1`：离线 wheel 构建、隔离安装、已安装 CLI 契约校验和模块导入通过。

当前独立配对库的令牌尚未与此 `host_id` 绑定，`GET /v1/host` 与正式快照响应也尚未实现。恢复会使事件序号倒退的旧备份时，仍须在受信任本地流程中更换身份并撤销旧凭据；本切片不能自动识别旧备份或承诺安全恢复。产品 Host 启动与设备重新配对验收仍开放。
