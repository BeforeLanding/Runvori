# DEV-005 命令邮箱快照与事件读取

日期：2026-10-26。需求关联：FR-03、FR-06；路线图：M1 Host 持久化与最小协议的读取前提。项目仍处 M0。

## 行为

- 外部线程通过已有有界命令邮箱请求单会话的原始存储快照，或按 `after_seq`、`before_seq`、`limit` 读取事件页；SQLite 连接仍由 Host 所有者线程独占。
- 快照带 `snapshot_seq`。以该序号作为增量页的 `after_seq` 可补读随后提交的事件；历史页保持升序返回。游标越界、同时给出两个边界和不存在的会话沿用事件库错误，不伪造空页。
- 每次读取使用事件库现有读事务和条数/字节上限。当前邮箱不实现长轮询，也未投影正式 Host 快照响应。
