### 打包与隔离安装

在贡献指南所述 `.dev/tmp` 和离线参数下执行：

```powershell
python -m pip wheel . --no-build-isolation --no-deps --no-index --wheel-dir .dev/wheels
python -m pip install --target .dev/package-check --no-index --no-deps .dev/wheels/runvori_host-0.0.1-py3-none-any.whl
python -c "import sys; sys.path.insert(0,'.dev/package-check'); from runvori.cli import main; sys.argv=['runvori','verify-contracts']; raise SystemExit(main())"
```

三项均成功，最后返回 14 份 schema 校验通过。wheel 位于被忽略的本地 `.dev/wheels`；属于技术探针，依赖 checkout 的契约和 workspace，不作为可部署 Host 服务发布。
