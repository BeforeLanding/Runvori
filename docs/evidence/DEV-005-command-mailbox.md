# DEV-005 Host 内部命令邮箱

日期：2026-10-26。需求关联：FR-02、FR-05、FR-08、FR-09；路线图：M1 Host 持久化与最小协议的线程边界前提。项目仍处 M0。

## 行为

- 外部线程仅能提交固定类型的回合启动、中断和按原操作者/请求号查询操作。邮箱有界；持有 SQLite 连接的 Host 所有者每轮最多处理一条，不把数据库连接交给请求线程。新回合 ID 由 Host 生成。
- 受理事务先提交，再向既有有界队列提交派发信号。队列满返回 `dispatch_signal_unavailable`；操作可能已持久提交，可按原请求号查询并显式重试，重复信号不会重复派发。
- 邮箱等待超时返回 `command_result_unknown`。原命令之后仍可能提交；调用方不得换请求号自动重试。未提供派发队列时在落库前拒绝执行请求。
- 不执行调用方提供的任意函数、命令或路径；未预期的内部异常不向请求线程暴露底层内容。

此入口仍是内部应用切片，没有 HTTP 路由、设备认证、TLS 配对、完整 Host 启动编排或真实 Codex 并发联调；不构成可供手机连接的产品服务。
