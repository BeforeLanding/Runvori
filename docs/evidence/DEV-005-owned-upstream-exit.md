# DEV-005 当前受管上游退出恢复切片

日期：2026-10-25。需求关联：FR-02、FR-09；路线图：M0 进程边界与 M1 Host 生命周期。项目仍处 M0。

## 行为

- 仅接受当前 Host 持有且未关闭的 Windows `StdioClient`。先核对所属 epoch，再关闭共享领域写门控；错误 epoch 不关闭连接。
- 关闭 stdio 连接及 kill-on-close Job 后，核对受管父进程已退出、Job 句柄已释放。从活动槽读取 run ID 与版本，执行统一 `upstream_exit` 恢复事务；中断非终态回合并释放活动槽。
- 连接关闭失败时不推进 epoch，写门控保持关闭。此时须由更高层核实或隔离进程后才能恢复服务。

## 验证与限制

`python scripts/check.py`：16 份契约通过；198 项测试运行，193 通过、5 项因本环境链接创建或回环连接限制跳过。新增 Windows 合成 peer 测试覆盖活动回合中断、进程及 Job 关闭、关闭故障后的写门控和错误 epoch 拒绝。

`scripts/smoke_package.ps1`：离线 wheel 构建、隔离安装、已安装 CLI 的 16 份契约核对及新增模块导入通过。

所属 epoch 由调用方提供并与数据库核对；此切片尚未独立证明传入连接是该 Host 的唯一上游，也不能证明 Host 崩溃后遗留进程已经隔离。产品启动/事件循环仍未接入。Job 关闭是进程生命周期约束，不是 Codex 执行权限沙箱；合成 peer 不代替真实 Codex 联调。
