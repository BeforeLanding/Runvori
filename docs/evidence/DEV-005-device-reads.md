# DEV-005 设备鉴权读取边界

日期：2026-10-26。需求关联：FR-01、FR-03、FR-06；路线图：M1 Host 最小协议。项目仍处 M0。

## 行为

- 新增内部 `DeviceReadGateway`，以 Q-05 的唯一有效设备令牌校验快照、增量事件和历史事件读取；未授权请求不进入 Host 命令邮箱。
- 每个请求在其线程打开配对记录，并在邮箱读取完成后再次核验令牌。长轮询拆为最多 250 毫秒的段，每段后重新查配对记录；撤销后拒绝返回该次读取结果。
- 历史读取不接受等待，取消信号沿用邮箱机制。网关返回内部存储形状，尚不构成正式 HTTPS 响应。

## 验证与限制

`python scripts/check.py`：16 份契约通过；264 项测试运行，259 通过、5 项因本环境链接创建或回环连接限制跳过。新增 4 项行为测试覆盖真实跨线程邮箱读取、未授权不读取、读取中撤销、撤销后错误不外泄、长轮询撤销/取消、历史读取和等待边界。`.\scripts\smoke_package.ps1`：离线 wheel 构建、隔离安装、已安装 CLI 契约校验和模块导入通过。

该入口不提供 HTTP、TLS、限流或 Host 身份/时间字段。每段最长 250 毫秒是请求线程正常运行时的授权复查间隔；SQLite 所有者失联可能导致邮箱读取超时，不承诺硬实时撤销。最后一次授权检查与未来 HTTP 发送之间仍存在竞态；正式响应发送前必须再次鉴权，且设备撤销需要主动取消在途请求。没有 Android 联调或真实网络验收。
