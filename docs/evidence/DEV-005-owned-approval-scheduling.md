# DEV-005 归属连接审批串行派发

日期：2026-10-25。需求关联：FR-04、FR-09；路线图：M0 上游映射与 M1 Host 生命周期。项目仍处 M0。

## 行为

- 有界内存队列只保存 `actor_id` 和 `request_id`，不保存决定或上游请求内容。队列满时拒绝新信号，不改变已持久记录。
- 持有 SQLite 连接和上游 stdio 的同一 Host 线程在事件轮询间处理一个队列项。从数据库重取决定，先领取一次发送权，再调用已有单次审批答复。重复项或已失效项跳过，不重新发送。
- 派发写入失败或结果未知时隔离当前连接，执行 `upstream_exit` 恢复并结束旧事件循环；恢复失败保持写门控关闭。

## 验证与限制

`python scripts/check.py`：16 份契约通过；215 项测试运行，210 通过、5 项因本环境链接创建或回环连接限制跳过。定向测试覆盖队列容量、重复项只发送一次、回合先终止时跳过派发、独立请求结束证据及写入失败后的未知状态与连接恢复。

`.\scripts\smoke_package.ps1`：离线 wheel 构建、隔离安装、已安装 CLI 的 16 份契约核对及新增模块导入通过。
